# Adding a Keycloak User

This guide describes how to add a new user to the Keycloak instance.

## Prerequisites

- Access to Keycloak Admin Console as Administrator user
- Information about the user to be added:
  - Username
  - First Name
  - Last Name
  - Email
  - Role

# Submit an analysis to Five Safes TES

Researchers interact with Five Safes TES (5S-TES) using the submission layer.
The submission layer ensures two of [the Five Safes](/explanations/concepts/five-safes): **Safe People** and **Safe Projects**.
This means you have to become a user, and be added to an approved project.

The submission layer has an HTTP API which accepts [TES messages](/explanations/concepts/tes#tes-messages-for-5s-tes).
For convenience, a TES Wizard and Workbench have been provided. Please see the links below for more information.
